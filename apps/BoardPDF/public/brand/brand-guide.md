# Manual de Identidad de Marca: BoardPDF (Precision Origami)

Este documento reúne las especificaciones técnicas y vectoriales del sistema de identidad visual de BoardPDF.

---

## 1. Concepto y Metáfora Visual
El concepto **Precision Origami** fusiona el origami geométrico con la ingeniería de precisión documental.
- **Geometría facetada**: Las facetas angulares generan profundidad tridimensional sin depender de degradados rasterizados, logrando una nitidez vectorial perfecta a cualquier resolución.
- **Pliegue de esquina**: El corte superior a 45 grados evoca de forma instantánea el pliegue universal del documento PDF digital.
- **Tono dual**: La yuxtaposición de carmesí brillante (`#E11D48`) y rojo borgoña (`#9F1239`) aporta contraste de iluminación y jerarquía visual.

---

## 2. Paleta Cromática Oficial

| Color | Hex | Uso Primario |
| :--- | :--- | :--- |
| **Carmesí Vivo** | `#E11D48` | Cuerpo frontal del documento, isotipo y acento "PDF" |
| **Rojo Borgoña** | `#9F1239` | Faceta de sombra lateral e isométrica |
| **Gris Platino** | `#CBD5E1` | Faceta interior de pliegue / profundidad |
| **Blanco Puro** | `#FFFFFF` | Cara exterior del pliegue y líneas de contenido |
| **Pizarra Oscura** | `#0F172A` | Tipografía principal en fondo claro |
| **Rosa Coral** | `#F43F5E` | Acento "PDF" para versión en modo oscuro |

---

## 3. Archivos Master Vectoriales Disponibles

- `favicon.svg`: Icono optimizado para escala 16×16 px y 32×32 px en pestañas y marcadores.
- `logo-horizontal.svg`: Versión horizontal primaria para cabeceras y barras de navegación (`viewBox="0 0 210 44"`).
- `logo-stacked.svg`: Versión vertical para pantallas de bienvenida, splash y exportaciones documentales.
- `logo-mark.svg`: Isotipo aislado en alta resolución (`viewBox="0 0 48 48"`).
- `logo-wordmark.svg`: Logotipo tipográfico puro (solo texto "BoardPDF" con acento carmesí).
- `logo-light.svg`: Logotipo para fondos claros (texto oscuro `#0F172A`).
- `logo-dark.svg`: Logotipo para fondos oscuros (texto blanco `#FFFFFF`).

## 4. Tipografía
- **Familia tipográfica**: `Inter, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- **Peso "Board"**: Semi-Bold / Bold (600 / 700)
- **Peso "PDF"**: Black / Ultra-Bold (900) con espaciado `-0.5px`
